### 1. EHVI 기대값 식 (덱 10장 · 원본 13주차 #9 · #10)

EHVI(x) = E_{f(x) ~ 𝒩(μ, σ²)} [ HV(P ∪ {f(x)}) − HV(P) ] ≈ (1/S) Σ_s ΔHV(f⁽ˢ⁾)

| 기호 | 뜻 |
|---|---|
| P | 현재 파레토 집합(관측 400건) |
| HV | 참조점–전선 사이 면적(초부피) |
| μ · σ | GP 예측 평균 · 표준편차 |
| S | 몬테카를로 표본 수 512 |

- 덱 말 식: 예측 분포에서 결과 512번 뽑기 → 뽑을 때마다 늘어난 면적 → 그 평균
- 실제 플랫폼 = BoTorch qNEHVI · 이번 주 = 독립 정규 2목표 + 몬테카를로(scripts/ehvi_select.py)

### 2. 가중합 점수 (덱 12장 계산기)

점수 = w · K* + (1 − w) · CED* · K* · CED* = 612건 최소–최대 정규화 값 · w = K 비중(0~1)

- 전선의 오목한 점은 어떤 w 로도 1위 불가 → 스칼라화만으로 전선 전체 탐색 불가(EHVI · 체비셰프 스칼라화의 이유)
