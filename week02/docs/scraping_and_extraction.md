# 자동 수집 · 코퍼스 색인 · 전문 확보 · LLM 추출 · 후보 등록

원본 11주차 덱 11-3 (#20 · #22 ~ #27)을 문서로 옮긴 자료. 슬라이드에서는 W02 4차시가 DOI 정규화(중복 제거)만 다룬다. 전문(PDF · XML)은 TDM(text and data mining) 허가 범위의 자료라 저장소에 올리지 않는다.

## 1. 자동 수집 파이프라인
API 질의(검색식 · 기간) → 서지 수집(DOI · 초록 · 저널) → 중복 제거(DOI · 제목 유사도) → 선별(포함 · 배제 기준) → 본문 확보(구독 범위 안에서).
- 선별 기준은 코드로 적는다: MD 계산 포함 · 물성 수치 보고 · 조성 명시.
- 이용 약관: 출판사 사이트 크롤링 대신 공식 API · 기관 구독 범위 준수.
- 증분 갱신: 마지막 수집 날짜 이후 문헌만 → 루프마다 짧은 실행.

## 4. LLM 구조화 추출
스키마(JSON): doi · material · additive{name, wt} · property · value · unit · temperature_K · method · evidence(표 번호 · 쪽).
- 스키마 강제: 자유 서술 대신 고정 필드 · 값이 없으면 null.
- 근거 필수: 표 번호 · 페이지 동시 출력 → 사람이 역추적.
- 단위 정규화: Pa·s · cP · mPa·s → 단일 단위 · 이상치 표시.
- 환각 관리: 표본 50건 사람 채점 → 정확도 측정 · 임계 미만이면 미사용.
(원본 덱의 JSON 예시 값 412 mPa·s 는 형식 예시이며 실제 논문 값이 아니다.)

## 5. 추출 결과와 필드 정규화 (`corpus_enhanced.csv`)
267편 문헌맵 중 전문 149편에 대해 추출. 필드별 값 기재 편수: method 149 · properties 149 · binder 149 · 실험 검증 여부 149 · 핵심 결과 139 · force_field 126 · ensembles 124 · additive 92 · aggregate 66 · ML 상세 6.

표기 분산의 예 · force_field 126편의 원문 표기 66종. COMPASS 를 포함한 표기만 16종(58편): `COMPASS II` 22 · `COMPASSII` 8 · `COMPASS-II` 1 · `Compass II` 1. 문자열 `"None"` 이 23편에 들어 있어 빈 값과 구분되지 않는다.

규칙: 추출 직후 표기 사전(canonical name) 매핑 · 목록형 값 분리 · `"None"` · `"nan"` → null · **정규화 전 집계 금지**. 추출값 자체의 정확도(사람 채점)는 이 파일에 기록돼 있지 않다.
