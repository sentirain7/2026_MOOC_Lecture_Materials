## 5. (객관식 · 난이도 중 · 차시 2-3 · 근거 덱 20장)

같은 프로젝트의 검색 기록 카드 가운데 「실험 문헌 원장」은 OpenAlex 질의 44개로 수집했지만, 결과가 README 에는 374편, CSV 에는 484행으로 적혀 있다. 이 카드의 숫자를 쓸 수 없다고 판단하는 이유로 가장 알맞은 것은?

① OpenAlex 는 공개 API 라서 결과를 신뢰할 수 없기 때문이다  
② MDPI · Hindawi 등을 제외해 편수가 줄었기 때문이다  
③ 갱신 기록이 없어 두 숫자가 언제 어떤 기준의 결과인지 알 수 없고, 다시 실행해 재현할 수 없기 때문이다  
④ 질의 수가 문헌맵(질의 10개)보다 많아 중복이 생겼기 때문이다
