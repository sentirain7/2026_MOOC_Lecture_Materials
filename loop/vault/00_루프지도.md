# 폐루프 지도

```
① 문헌 papers/ (Zotero → library.bib → 논문 노트)  ──lit_extract──▶  표적 2개(밀도 · CED)
② 설계 후보 「아스팔트 평균 분자」 168개 (scripts/library.py · config/loop.yaml)
③ MD 워크플로우 (../mdworkflow: 분자 → 힘장 → 셀 → LAMMPS → 밀도 · CED)
④ 대리모델 gp · rf · xgb (μ · σ)
⑤ 능동학습 체비셰프 EI → 다음 후보 분자 2개
⑥ 환류 runs/ · rounds/ 노트 → 다시 ③
```

- 논문 노트: papers/ (표적 = loop_role: target)
- 실행 노트: runs/ (계산 하나 = 노트 하나 · 근거 문헌에 링크)
- 라운드 노트: rounds/ (round_0 → round_1 → …)
- 그래프 보기(Obsidian 왼쪽 막대 「그래프 뷰」): 문헌 ↔ 실행 ↔ 라운드가 한 그림으로 이어진다
