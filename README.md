# 2026 MOOC 강의자료

**건설소재 역설계 도구 개발을 위한 AI와 분자동역학 활용**
*AI and Molecular Dynamics for Developing Inverse-Design Tools for Construction Materials*

한국건설기술연구원 윤태영(Taeyoung Yun) · 13주 강좌(주당 50분) · 2026

대학원 연구자를 대상으로 분자동역학 기초이론 · LAMMPS 시뮬레이션 · 그래프 신경망(GNN) 기반 기계학습을 단계적으로 학습하고,
이를 문헌 고찰부터 능동학습 · 다목적 최적화에 이르는 자율 탐색 파이프라인으로 통합하여, 아스팔트 · 시멘트 등 건설소재의
역설계(inverse design) 도구를 직접 설계 · 구현할 수 있는 연구 역량을 기르는 강좌입니다.

## 여는 방법

- **PDF**: 바로 열립니다. 버튼으로 조작하는 「라이브」 슬라이드는 첫 화면 상태로만 보입니다.
- **강의덱_HTML(단독 파일판)**: 파일을 내려받아 더블클릭합니다. ← → 로 넘기고, Home · End 로 처음 · 끝으로 갑니다.
- **발표용 HTML 폴더판**: 폴더 전체를 내려받아 로컬 웹 서버로 엽니다(파일을 바로 열면 슬라이드 런타임이 동작하지 않습니다).
- 저장소 전체 내려받기: 위쪽 **Code → Download ZIP** 또는 `git clone https://github.com/sentirain7/2026_MOOC_Lecture_Materials.git`
