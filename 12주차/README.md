# 12주차 — 자율 탐색 파이프라인 (1) — 파이프라인 구조와 데이터 큐레이션

**학습목표**: 자율 탐색 파이프라인의 구성과 후보 생성·데이터베이스 큐레이션을 이해한다.

| 차시 | 주제 | 내용 | 분 |
|---|---|---|---|
| 12-1 | 파이프라인 구조 | 자율 탐색 파이프라인의 구조를 다루며, 능동학습 단계는 9·10주의 대리모델(XGBoost+SHAP·GNN)을 활용한다. | 12 |
| 12-2 | 후보 분자 생성 | 라이브러리와 생성 규칙으로 후보 분자를 생성한다. | 12 |
| 12-3 | PostgreSQL 데이터 큐레이션 | PostgreSQL 데이터베이스에 시뮬레이션 데이터·메타데이터를 큐레이션. | 16 |
| 12-4 | 이상치 처리·재현성 | 이상치·실패 실행 처리와 재현성 확보. | 10 |
