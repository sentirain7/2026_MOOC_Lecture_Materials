덱(W13)은 이 저장소에서 직접 돌린 COMID MD 336행 결과로 같은 논점을 다시 확인한다. 아래는 원본 덱(10주차 보충A · XGBoost/GP · COMID 2026-07 실행)의 표와 수치를 **원문 그대로** 옮겼다. 강의 영상에는 나오지 않으며 깊이 읽을 사람을 위한 자료다.

## 5. 지표 정의 · 원본 #15 (덱 15장)
- RMSE = √(Σ(ŷᵢ − yᵢ)² / n) · 큰 오차에 민감 · 물성 단위
- MAE = Σ|ŷᵢ − yᵢ| / n · 전형적 오차 · 이상치에 둔감 · RMSE ≥ MAE
- R² = 1 − Σ(ŷᵢ − yᵢ)² / Σ(yᵢ − ȳ)² ≈ 1 − RMSE² / σ_y² (σ_y = 시험값 표준편차)
- 구현: `scripts/common.py` 의 `metrics()`

## 10. 덱에서 옮긴 식 (2026-11-14 · 규칙 16 · 덱 15 · 16장)

덱 15장은 핵심 식 1개만 말 식으로 남김: **R² = 1 − 남은 오차 ÷ 원래 흩어짐**. 기호식 · 기호표는 아래로 옮김(값 변경 없음).

- RMSE = √( Σ(ŷᵢ − yᵢ)² / n ) · MAE = Σ|ŷᵢ − yᵢ| / n · R² = 1 − Σ(ŷᵢ − yᵢ)² / Σ(yᵢ − ȳ)²
- 기호표

| 기호 | 뜻 |
|---|---|
| yᵢ | 시험 점의 MD 값 |
| ŷᵢ | 모델 예측값 |
| ȳ | 시험 점 평균 |
| n | 시험 점 수 |

- 덱 16장 계산기 출처 줄에 있던 관계식: R² ≈ 1 − RMSE² / σ_y² (σ_y = 시험값 표준편차 · 계산기 표시 이름 「시험 폭」)
- 덱 15장 그림: 잔차 막대 8점 + 오른쪽 막대 3개(RMSE · MAE · MD 반복 오차 0.0027 g/cm³)
