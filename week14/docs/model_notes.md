## 9. 원본 #19 · 누수 없는 학습 절차 (코드 원문)

```python
from sklearn.model_selection import GroupKFold
import xgboost as xgb
gkf = GroupKFold(n_splits=5)
for tr, va in gkf.split(X, y, groups=comp_id):
    mu, sd = X[tr].mean(axis=0), X[tr].std(axis=0)
    X_tr, X_va = (X[tr]-mu)/sd, (X[va]-mu)/sd
    model = xgb.XGBRegressor(
        n_estimators=800, learning_rate=0.03, max_depth=5,
        subsample=0.8, colsample_bytree=0.8, reg_lambda=1.0)
    model.fit(X_tr, y[tr])
    pred = model.predict(X_va)
```

- 그룹 분할(GroupKFold): comp_id 로 묶어 같은 조성이 학습 · 검증 양쪽에 걸치지 않게 배치
- 정규화(standardization) 시점: 학습 폴드에서 μ · σ 를 구해 검증 폴드에 적용
- 라벨 변환: 점도는 log10 변환 후 학습 · 보고 시 역변환
- 표본 가중: MD 오차가 큰 라벨에 작은 가중치 부여

W14 `scripts/common.py` 의 `cv()` 가 이 절차 그대로다(그룹 = 바인더|첨가제|노화).

## 16. 원본 #31 · 특징 재정련 5단계 (원문)

1. 기여도 ≈ 0 변수 확인 → SARA 4종 제거
2. 다른 특징으로 예측되는 변수 확인 → additive_wt (R² 0.9996) 제거
3. 상관 매우 높은 쌍 확인 → r 0.96 · 0.98 → 1개만 유지
4. 타깃 정의에 포함된 입력 확인 → CED ↔ e_intra → 해당 타깃에서 제외
5. 라벨 · 원핫을 물리 수치로 대체 → 노화 → 산화지수 · 첨가제 → 분자특성
