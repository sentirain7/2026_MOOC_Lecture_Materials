## 1/5 · 수퍼그래프(supergraph) · 분자 1개 = 노드 1개 (원본 #35)

- **원자 그래프의 한계**: 바인더 = 분자량 400 이상 거대분자 60종 이상의 혼합물 · 원자 전체를 노드로 두면 비결합 상호작용까지 명시 → 계산량 급증
- **수퍼그래프 표현**: 거대분자 하나 = 부분그래프(subgraph) = 노드 하나 · 분자 사이 비결합 상호작용 = 엣지 · 셀 전체 = 수퍼그래프
- **장점**: 3차원 배치 정보 유지 · 원자 단위 상호작용 전체를 모델링하지 않아 비용 대폭 감소 · 첨가제–바인더 상호작용 표현 유지
- **중요도가 커지는 부분**: 노드 · 엣지에 담을 정보 · 표현자 선택 = 모델 성능 결정 요인

- 평균 각도: 노드 i · j 의 반경이 겹치는 영역의 제3 노드(파란 테두리)로만 계산 · 겹침 밖 노드(빨간 테두리) 제외 → 국소 배치만 반영

## 4/5 · 예측 결과 · 모델 간 차이는 hold-out 에서 발생 (원본 #38)

| 모델 | 밀도 hold-out R² |
|---|---|
| SG-Graphormer3D | 0.982 |
| XGBoost(엣지 특징) | 0.941 |
| RF(엣지 특징) | 0.898 |

- 학습 성능은 표 모델 우세: Train R² 은 RF · XGB 가 0.998~1.000 · 처음 보는 첨가제(그래핀)에서 성능 급락 = 차이의 원인
- 총에너지(TotalEnergy)는 양상 상이: 조성이 거의 결정 → XGBoost hold-out R² 0.993 · 합 · 평균 같은 통계 기술자만으로 충분
- 그림 축 = TotalEnergy(계 총에너지) · CED(응집에너지밀도)와 다른 양 · 논문 절 제목의 「CED」 는 본문 · 그림상 총에너지
- 읽는 법: 밀도는 3차원 패킹이 지배 → 위치 정보를 담는 그래프가 필요 · 에너지는 조성이 지배 → 빠른 표 모델로 충분
