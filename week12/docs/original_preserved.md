# 원본 08주차 보존 문서 · 덱에 싣지 않은 내용

내용 보존 규칙에 따라 원본 08주차 덱에서 W12 덱 본문에 들어가지 않은 부분을 원문 그대로 옮긴다.
수치는 원본 덱 값이며 이 저장소에서 다시 계산하지 않았다.

## 원본 7장 · 콘크리트의 활용과 특성 · 강도와 내구성

- **강도**: 압축강도 20~60 MPa 급 · 인장은 그 1/10 수준 · 강도 결정 요인 = 수화 생성물 C-S-H 겔의 결합과 공극률(porosity)
- **내구성**: 탄산화(carbonation) · 염해(chloride attack) · 동결융해(freeze–thaw) · 황산염 침해(sulfate attack) · 공통점 = 물과 이온의 공극 이동에 따른 상 변화
- **시간 의존**: 수화 지속 기간 수 시간 ~ 수십 년 → 초기 반응은 MD, 장기 거동은 상위 모델로 분담
- **분자 모델의 몫**: 클링커 상의 반응성 · C-S-H 의 탄성계수 · 이온과 물의 확산 · 배합 설계에 쓰는 상수의 출처
- 강도 · 내구성 = 생성된 상의 종류와 양의 결과 → 8-2 에서 수화 반응부터 계산

W12 덱에서는 5장(수화도 α(t) · MD 가 보는 구간)과 6장(아스팔트 ↔ 시멘트 카드)이 이 장의 일부를 대신한다.
