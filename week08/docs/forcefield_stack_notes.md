## 1. hybrid/overlay 입력 예시 (원래 덱 13장 · 원본 05주차 #26 · 07주차 #17)

덱 13장은 비유 그림(설계도 한 벌 · 시방서 3종)으로 바뀌었고, 핵심 규칙은 22장(조건부 짝 처리)으로 합쳤다.

```
# 원본 05주차 #26 · 조건부 짝에서 교차쌍 명시
pair_style  hybrid/overlay lj/cut 12.0 lj/cut 12.0 coul/long 12.0
pair_coeff  * *  coul/long            # 쿨롱은 한 번만
pair_coeff  1 1  lj/cut 1  0.086 3.400
pair_coeff  5 5  lj/cut 2  0.155 3.166
pair_coeff  1 5  lj/cut 1  0.116 3.283   # 이종쌍 직접 기재
special_bonds amber                   # 계 전체에 하나만

# 오늘 in.stack · 전부 12-6 · 단일 스타일
pair_style   lj/cut/coul/long 12.0
pair_modify  mix arithmetic         # 28 이종쌍 자동 생성 (로그 확인)
```

- 숫자 = 03주차 #33 예시(문헌 대표값 반올림) · in.stack 로그: 「Generated 28 of 28 mixed pair_coeff terms」
- 중첩 = 합산: 같은 원자쌍에 pair 항이 더해짐 · 두 번 적으면 이중 계산
- 자동 검사: 생성기가 「정의되지 않은 pair_coeff」 를 사전 검출 · 12-6 + 9-6 은 생성 단계에서 거부
- 검증 연결: 혼용 계는 W09 물성(단성분 → 혼합 → 계면)으로 검증한 뒤 데이터에 추가

## 2. 이종쌍 재정의 ② 형식 변환 식 (원래 덱 22장 카드)

- σ = r_min / 2^(1/6) · 9-6 형식의 최소점 위치를 12-6 형식으로 옮김 · 최소점만 일치(곡선 모양은 다름)

## 3. 이종쌍 수치 예 (덱 20장 · 제목에서 부제 · 노트로 옮김)
