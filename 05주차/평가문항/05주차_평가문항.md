# 05주차 평가문항 — LAMMPS 활용 (2) — 자동 스크립트 생성·자기교정과 다중 힘장 스택

문항 6개. 문항마다 유형 · 난이도 · 차시 · 정답 · 해설 · 근거 슬라이드를 적었다. 원본 데이터는 같은 폴더의 `q05.json`.

## 1. (객관식 · 난이도 하 · 차시 5-1)

자동 스크립트 생성 파이프라인에서 한 실행의 온도 조건을 바꿔야 할 때 올바른 방법은?

① 조성 명세(spec.yaml)를 수정하고 입력 세트를 다시 생성한다  
② 렌더된 in 스크립트의 해당 줄만 직접 수정해 제출한다  
③ 템플릿(in.equil.j2)에 새 온도 값을 숫자로 직접 적는다  
④ 생성된 data 파일 헤더에 온도 값을 추가해 제출한다  

- **정답**: ① 조성 명세(spec.yaml)를 수정하고 입력 세트를 다시 생성한다
- **해설**: 조성 명세는 유일한 기준(single source of truth)이고 입력 파일은 산출물이므로, 값을 바꿀 때는 명세를 고쳐 다시 생성한다. in 파일을 손으로 고치거나 템플릿에 숫자를 하드코딩(hard-coding)하면 그 실행만 경고 없이 명세와 달라져 재현할 수 없고, data 파일은 온도를 정하는 곳이 아니다.
- **근거 슬라이드**: 8번 「생성 파이프라인」

## 2. (OX · 난이도 중 · 차시 5-1)

실행 패키지에 입력 해시(input hash)를 부여해 두면, 같은 명세로 다시 생성했을 때 같은 해시가 나오므로 이미 완료된 실행을 건너뛸 수 있다.

- **정답**: O
- **해설**: 입력 해시는 in·data·ff·spec.lock 네 파일의 내용으로 계산하므로 같은 명세를 재생성하면 같은 해시가 나온다. 이 멱등성(idempotency) 덕분에 완료된 실행은 생략되어 수백 개 스윕(sweep)을 반복해도 중복 계산이 생기지 않는다.
- **근거 슬라이드**: 15번 「실행 패키지」

## 3. (객관식 · 난이도 상 · 차시 5-2)

층상 부모 셀의 어닐 램프에서 Bond atoms missing 오류가 매번 다른 스텝에서 3회 연속 발생했다. 필름 중앙 높이는 10k 스텝 185.5 Å에서 40k 스텝 251.1 Å까지 증가폭이 점점 커지며 올라갔다. 원인과 조치로 옳은 것은?

① 패킹 접촉 문제이므로 속도 시드만 바꿔 같은 설정으로 다시 제출한다  
② 진공층 부족에 따른 PPPM 범위 이탈이므로 진공 두께를 확대한다  
③ flying ice cube 인공물이므로 fix momentum으로 z 방향 질량중심 운동을 제거한다  
④ timestep이 과도하므로 Δt를 절반으로 줄이고 최소화부터 다시 실행한다  

- **정답**: ③ flying ice cube 인공물이므로 fix momentum으로 z 방향 질량중심 운동을 제거한다
- **해설**: 필름이 등가속으로 떠오르는 것은 서모스탯이 질량중심 병진운동을 키우는 flying ice cube 인공물(artifact)의 징후이며, 평형 NVT에 fix momentum 1 linear 0 0 1 을 넣자 높이가 174.1–174.2 Å로 고정되었다. 시드 재시도는 같은 조건의 반복이었고, 증상이 PPPM out of range 가 아니므로 진공 확대나 Δt 축소로는 원인을 해결할 수 없다.
- **근거 슬라이드**: 20번 「사례 2 원인 분석과 3단계 대응」

## 4. (단답형 · 난이도 중 · 차시 5-2)

자기교정 루프에서 힘장 생성이 실패했을 때 근사 파라미터로 우회하지 않고 실패로 기록해 사람이 검토하게 하는 원칙의 이름은?

- **정답**: fail-closed (인정: fail-closed · fail closed · failclosed · 페일 클로즈드 · 실패 시 차단)
- **해설**: fail-closed(실패 시 차단)는 힘장 생성이 실패하면 근사 파라미터로 몰래 우회하지 않고 실패로 기록해 사람이 검토하게 하는 원칙이다. 역설계 데이터에서는 출처를 모르는 값 하나가 빈칸 하나보다 더 해롭기 때문이다.
- **근거 슬라이드**: 18번 「실패 유형별 처방」

## 5. (OX · 난이도 중 · 차시 5-3)

FF-neutral 중립 토폴로지에는 원소·좌표·결합 차수와 함께 원자별 부분전하 q를 기록해 두어, 힘장을 바꿀 때도 같은 전하를 재사용한다.

- **정답**: X
- **해설**: 틀린 부분은 부분전하를 기록한다는 내용이다. 중립 토폴로지는 원소·좌표·결합 차수·분자 ID만 담고, 타입 번호·전하 q·ε·σ·special_bonds는 담지 않는다. 전하는 힘장의 전하 모델(GAFF2 경로는 AM1-BCC)이 정하는 값이므로 힘장마다 따로 계산해야 한다.
- **근거 슬라이드**: 23번 「중립 토폴로지 가시화 (1/2)」

## 6. (객관식 · 난이도 하 · 차시 5-4)

다중 힘장 스택(force-field stack)의 검증 수준 가운데 research_only 의 의미로 옳은 것은?

① 계산 결과가 틀린 것으로 판정되어 데이터에서 삭제할 스택  
② 실험값과 충분히 대조되지 않아 validated 결과와 섞지 않는 스택  
③ 구현되지 않아 제출 시점에 코드가 제출을 차단하는 스택  
④ 운영자 승인만 받으면 validated 결과와 함께 학습에 쓰는 스택  

- **정답**: ② 실험값과 충분히 대조되지 않아 validated 결과와 섞지 않는 스택
- **해설**: research_only는 계산이 틀렸다는 뜻이 아니라 아직 실험값과 충분히 대조하지 않았으므로 validated 결과와 섞지 말라는 뜻이다. 미구현으로 제출을 막는 것은 blocked(예: pcff_iff_v1)이고, 운영자 승인은 ionic 라우팅 경로의 조건이다.
- **근거 슬라이드**: 28번 「스택 이름과 검증 수준」
