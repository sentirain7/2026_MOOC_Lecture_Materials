9-1 · SMILES → RDKit

SMILES 한 줄에서 숫자 벡터까지

descriptors.py
from rdkit import Chem from rdkit.Chem import Descriptors, AllChem mol = Chem.MolFromSmiles("c1ccc2ccccc2c1")
d = dict(mw = Descriptors.MolWt(mol), log_p = Descriptors.MolLogP(mol), tpsa = Descriptors.TPSA(mol), n_aro_ring = Descriptors.NumAromaticRings(mol))
fp = AllChem.GetMorganFingerprintAsBitVect( mol, radius=2, nBits=1024) # ECFP4
row = {**d, **{f"fp{i}": b for i, b in enumerate(fp)}}
SMILESSMILES(Simplified Molecular-Input Line-Entry System): 분자 구조의 문자열 한 줄 표기 — 3주차 SARA 대표 분자 · 7주차 첨가제 라이브러리 모두 이 형식
기술자RDKit(오픈소스 화학정보학 라이브러리) 계산 · MW · logP · TPSA · 방향족 고리 수 — 해석 가능한 수십 개 수치
fingerprintECFP4 — 반경 2 이내 부분구조의 존재 여부를 1024 비트로 표시 · 해석 어려움 · 구조 차이에 민감
출력분자 하나 = 표 한 줄 · 열 이름 고정 필요 (이후 병합 조건)
비트 수 증가 → 표현력 상승 · 작은 데이터에서는 과적합 — 1024에서 시작

from sklearn.model_selection import GroupKFold import xgboost as xgb gkf = GroupKFold(n_splits=5) for tr, va in gkf.split(X, y, groups=comp_id): mu, sd = X[tr].mean(axis=0), X[tr].std(axis=0) X_tr, X_va = (X[tr]-mu)/sd, (X[va]-mu)/sd model = xgb.XGBRegressor( n_estimators=800, learning_rate=0.03, max_depth=5, subsample=0.8, colsample_bytree=0.8, reg_lambda=1.0) model.fit(X_tr, y[tr]) pred = model.predict(X_va)
