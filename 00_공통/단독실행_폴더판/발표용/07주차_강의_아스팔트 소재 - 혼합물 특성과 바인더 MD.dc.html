7-1 · FRACTIONATION

SARA 분획(fractionation) 절차와 역설계 기준점

SARA 는 분자식이 아니라 용해도 기준 분류
개별 화합물 식별이 아닌 용매 용해도 기준 4분류 (ASTM D4124)
S → A → R → As = 극성 · 방향족성 · 분자량이 커지는 순서
한 분획 안 수천 종 혼재 · 대표 분자 = 분획 평균 성질의 대표값
이 분류로 모델을 구성하는 이유
분획비는 실험으로 측정되는 값 → 모델 조성을 맞출 기준점이 존재 (다음 슬라이드의 검증 지표)
물성과의 대응 명확: 노화 = A → R → As 이동 · As 증가 → 강성 · 취성 증가
역설계의 설계 변수 = 네 분획의 비율 + 분획 내 분자 구성

7-3 · FF STACK

바인더 시스템의 힘장 스택

OPLS-AA
OPLS-AA(Optimized Potentials for Liquid Simulations, All-Atom) · 탄화수소 · 방향족 유기 분자의 응집 거동 재현에 적합 · 밀도 · 점도 재현 안정
적용 영역: SARA 대표 분자 벌크
GAFF2
GAFF2(General AMBER Force Field 2) · 임의 유기 분자 자동 타이핑 가능 · 21종 첨가제처럼 종류 · 구조가 다양한 경우에 유리
적용 영역: 첨가제 · 신규 분자
ReaxFF
반응성 힘장(ReaxFF, reactive force field) · 결합 생성 · 절단 계산 · 산화 노화처럼 결합이 바뀌는 과정에만 제한 적용
적용 영역: 산화 노화 구간 · 작은 계
원칙: 한 물성 비교 데이터셋 안 힘장 혼용 금지 · 힘장이 다르면 값의 척도도 상이
스택 필요 조건: 영역의 물리적 구분 · 유기상(고전) + 광물상(전용 파라미터) + 반응 구간(ReaxFF)
7-3 · HYBRID / OVERLAY

힘장 스택의 입력 파일 구현

ff_stack.inc
pair_style hybrid/overlay & lj/cut 12.0 buck 12.0 coul/long 12.0
pair_coeff * * coul/long # 쿨롱: 모든 쌍 1회 pair_coeff 1*18 1*18 lj/cut # 유기상 LJ
pair_coeff 19*24 19*24 buck # 광물상 Buckingham
pair_coeff 1*18 19*24 lj/cut & ${eps_cross} ${sig_cross} # 교차항 — 명시 지정
중첩hybrid/overlay = 같은 원자쌍에 여러 pair 항 합산 · 중복 지정 = 이중 계산
교차항서로 다른 힘장의 원자쌍 = 혼합 규칙(mixing rule) 자동 적용 없음 · 교차항(cross term) 값 직접 입력 · 출처 기록
전하힘장별 전하 산출 방식 상이 · 한 계 안 전하 체계 혼용 → 계면 에너지 편향
