기준은 강의계획서(`tools/syllabus.json`)의 차시 구성이다. 규칙은 `STYLE_GUIDE.md` §2.3(삭제 금지 · 부록 · 공유)과 §8(가시성 우선 분할 · 흐름 정리)을 따른다.
슬라이드 번호 `#n`은 커밋 `9557563` 기준이다. 다른 덱에서 복사할 때는 반드시 `git show 9557563:"파일명"`으로 읽는다. 작업 중인 파일에서 읽지 않는다.

표기
- **유지**: 그 차시에 그대로 둔다.
- **이동**: 같은 덱 안에서 다른 차시로 옮긴다.
- **복사←**: 다른 덱 슬라이드를 복사해 온다. 원본은 그대로 둔다.
- **부록**: 덱 맨 뒤 부록으로 옮긴다.
- **신규**: 새로 작성한다. 자료는 `tools/source_inventory.md`에서 먼저 찾는다.

## 공통 체크리스트 (덱마다)
1. 표지 부제, 구성 슬라이드 행(계획서 차시명·시간), 구분 슬라이드 제목(계획서 차시명), 정리 슬라이드를 새 구성에 맞춘다.
2. `python3 tools/renumber_step2.py --only "파일"` → screen-label과 시간을 정리한다.
3. `python3 tools/normalize_style.py "파일"` → `python3 tools/check_style.py <주차>`에서 ERROR 0을 확인한다.
4. `tools/check_overflow.js <주차> --shots <scratch>` → 넘침 0을 확인하고, 바뀐 슬라이드는 스크린샷으로 직접 본다.
5. 이동·복사·분할·부록은 모두 `tools/moves/wNN.md`에 기록한다.
