# 힘장 · 원소 · LAMMPS 호환성 — DT-Lab 권장 조합

DT-Lab의 3층 계(광물 | 물 | 단순 분자 바인더)를 CPU LAMMPS에서 **안정적으로** 돌리기 위한 힘장 조합과 그 근거, 검증 절차를 정리했다. 구조 생성 프롬프트(`PROMPTS_STRUCTURE.md` S1 · S2 · S6 · S7)는 이 문서를 기준으로 한다.

- 작성일: 2026-09-22
- LAMMPS 기준판: stable 22Jul2025 (conda-forge 2025.07.22)

## 이 문서를 쓰는 순서
1. §1 권장 조합을 확인한다. 바꾸려면 §2 비교표에서 이유를 먼저 본다.
2. §3 원소 범위표로 새 분자가 허용 원소만 쓰는지 확인한다(11주차에 첨가제를 추가할 때).
3. §4 LAMMPS 설정표를 템플릿에 그대로 쓴다.
4. §5 알려진 함정을 코드 검사 항목으로 넣는다.
5. §6 검증 사다리 V1~V9를 **순서대로** 통과시킨다. 앞 단계가 실패하면 다음 단계로 가지 않는다.

## 1. 권장 조합

| 층 | 힘장 | 전하 | 원소 | 비고 |
|---|---|---|---|---|
| 바인더 · 첨가제 | **GAFF2** (AmberTools 26 `gaff2.dat`) | **AM1-BCC** (sqm) | C · H · O · N · S | 유기 분자 범용. 파라미터를 자동으로 부여할 수 있다(antechamber · parmchk2) |
| 물 | **SPC/E** (강체) | 고정 −0.8476 / +0.4238 | O · H | `fix shake`로 고정. 원 논문 값과 대조한다 |
| 광물 | **ClayFF** (Cygan 2004) | 고정(원 논문 값) | Si · O · H (석영), Ca · O · H (portlandite) | 골격은 비결합. **결정 전체를 고정**한다 |

**이 조합을 고른 이유**
1. **세 힘장이 모두 LJ 12-6 + 점전하 쿨롱 형식이다.** `pair_style lj/cut/coul/long` 하나로 전체 계를 계산하고 `hybrid`를 쓰지 않는다. 형식이 다른 힘장을 섞을 때 생기는 교차항 정의 문제가 없다.
2. **혼합 규칙(combining rule)이 같은 계열이다.** GAFF2와 ClayFF 모두 Lorentz–Berthelot 산술 평균 기준으로 쓰인다. `pair_modify mix arithmetic` 한 줄로 이종쌍(unlike pair)이 정해진다. 근거: LA `docs/theory/clayff-gaff2-mixing-theory.md`
3. **ClayFF는 물 모델(SPC 계열)과 함께 개발되었다.** ClayFF + SPC/E 조합은 광물–물 계면 연구에서 널리 쓰인다. 원 논문의 유연 SPC와 강체 SPC/E의 차이는 한계로 기록한다.
4. **결합 · 각 · 이면각 형식이 LAMMPS 기본 스타일로 정확히 옮겨진다.**
   - bond `harmonic` · angle `harmonic` · dihedral `fourier` · improper `cvff`
   - 변환 뒤 에너지를 OpenMM과 항별로 대조한다(V1).
5. **모든 스타일이 기본 CPU 패키지(MOLECULE · KSPACE · RIGID)에 있다.** 특별한 빌드가 필요 없다. conda-forge CPU 판과 소스 빌드 판 모두에서 같다.

## 2. 검토한 대안과 채택하지 않은 이유

| 대안 | 문제 | 판정 |
|---|---|---|
| OPLS-AA (바인더) | 원래 **기하 평균** 혼합 규칙. ClayFF(산술)와 섞으려면 모든 교차쌍을 직접 지정해야 한다. 자동 부여 도구가 외부 서비스(LigParGen)에 의존한다 | 비교 실습(5-3 중립 토폴로지)에만 사용 |
| COMPASS · PCFF (class II) | LJ **9-6** 형식(`lj/class2`). ClayFF 12-6과 교차항을 정의할 수 없다. COMPASS 파라미터는 상용 배포 조건이다 | 채택 안 함 |
| CVFF + INTERFACE-FF (결합형 실리카) | 광물 골격이 결합형이라 표면을 고정하지 않아도 된다. 대신 IFF 파라미터 배포 조건과 CVFF 유기 파라미터 자동화가 어렵다 | 대안 B로 기록(차기 과제) |
| TIP3P · TIP4P/2005 (물) | TIP4P는 가상 자리(M site) 때문에 `lj/cut/tip4p/long`이 필요하고 다른 스타일과 섞기 어렵다. TIP3P는 가능하지만 ClayFF 계열 문헌은 SPC 계열이 주류다 | SPC/E 채택 |
| ReaxFF | 반응성 힘장이라 계산 비용이 10~100배다. 쿨롱을 QEq로 처리하므로 다른 힘장과 섞을 수 없다 | 8주차 데모에만 사용 |
| ML 힘장 (SNAP 등) | 참조 데이터 범위 밖에서는 신뢰할 수 없다 | 8주차 데모에만 사용 |

## 3. 원소 · 분자 허용 범위

| 원소 | 허용 층 | 힘장 | 주의 |
|---|---|---|---|
| C · H | 바인더 · 첨가제 | GAFF2 | |
| O | 바인더(카복실 · 페놀 · 에터), 물, 광물 | GAFF2 · SPC/E · ClayFF | **같은 원소라도 층마다 다른 타입** (§5.1) |
| N | 첨가제(아민) | GAFF2 | 중성형만 쓴다. 양성자화된 아민(−NH₃⁺)은 쓰지 않는다 |
| S | 수지 대용(싸이오펜) | GAFF2 | 방향족 황. 황화물 · 설폭사이드는 추가할 때 V1 재검증 |
| Si | 광물 | ClayFF `st` | |
| Ca | portlandite | ClayFF `cah` | |
| 그 밖의 원소(금속 이온 · 할로젠 · P 등) | — | — | **허용하지 않는다.** 필요하면 이 표와 V1~V4를 다시 검증한 뒤 추가한다 |

**분자 조건** (11주차 신규 첨가제에 적용하는 자동 검사)
- 순전하 0, 라디칼 없음, 원자 수 ≤ 120
- 허용 원소만 포함
- 반응성 작용기 없음: 산 염화물, 이소시아네이트 등. 고전 힘장에서는 반응이 일어나지 않기 때문이다.
- antechamber · parmchk2가 경고 없이 끝나야 한다. frcmod에 `ATTN, need revision`이 있으면 실패다.

## 4. LAMMPS 설정 (템플릿 기준값)

```lammps
units           real
atom_style      full
boundary        p p f                  # 3층 계. 벌크는 p p p
pair_style      lj/cut/coul/long 12.0
pair_modify     mix arithmetic         # 벌크만 tail yes, 계면계는 tail 없음
kspace_style    pppm 1.0e-4
kspace_modify   slab 3.0               # 3층 계만
bond_style      harmonic
angle_style     harmonic
dihedral_style  fourier
improper_style  cvff
special_bonds   amber                  # lj 0 0 0.5 / coul 0 0 0.8333333
neighbor        2.0 bin
neigh_modify    delay 0 every 1 check yes
timestep        2.0                    # fix shake 사용 시. 검증용 1.0 비교
```

| 항목 | 규칙 | 이유 |
|---|---|---|
| special_bonds amber | 전체 계에 한 번 | GAFF2의 1-4 스케일이다. 물 · ClayFF에는 1-4 쌍이 없어 영향이 없다(O–H 1-2, H–O–H 1-3만 제외) |
| SHAKE 대상 | GAFF2 X–H 결합 + SPC/E 결합 · 각. **ClayFF 수산기 O–H는 제외** | 결정 원자는 고정이다. 수산기 H는 조화 결합으로 두고, 2 fs에서 안정한지 V3에서 확인한다(불안정하면 1 fs) |
| 결정 고정 | `fix setforce 0 0 0` + 속도 0, 온도 조절 · SHAKE 그룹에서 제외 | ClayFF 골격이 비결합 모델이라, 고정하지 않으면 표면 원자가 이탈한다 |
| 결정 내부 쌍 | `neigh_modify exclude group quartz quartz` | 고정 원자 사이 힘은 필요 없다. CPU 시간을 줄인다(kspace는 제외되지 않음) |
| 인장 그립 | `fix move linear`, SHAKE · 온도 조절 그룹에서 제외 | 강체로 이동하는 원자에 구속 · 온도 조절을 겹치지 않는다 |
| z 경계 | `p p f` + 진공 ≥ 인장 최대 변위 + 20 Å | `f` 경계 밖으로 나간 원자는 손실(lost atoms)로 계산이 중단된다 |

## 5. 알려진 함정 — 코드에서 자동 검사

### 5.1 타입 이름 충돌 (가장 중요)
GAFF2에도 **`oh`(수산기 O) · `ho`(수산기 H) · `ow` · `hw`** 타입이 있다. ClayFF도 `oh` · `ho`를 쓴다. 이름만으로 타입을 합치면 페놀 · 카복실산 첨가제의 수산기와 석영 실라놀이 **같은 타입으로 합쳐져 전하 · LJ가 뒤섞인다.**
- **규칙: 타입 이름에 힘장 접두어를 붙인다.** `g2_oh`, `g2_ho`(GAFF2) / `sw_OW`, `sw_HW`(SPC/E) / `cf_oh`, `cf_ho`, `cf_st`, `cf_ob`, `cf_cah`(ClayFF)
- 병합 코드는 접두어가 다른 타입을 절대 합치지 않는다. 테스트: 페놀 첨가제 + 석영 조립 뒤 `g2_oh` ≠ `cf_oh`

### 5.2 LJ가 0인 수소
GAFF2 `ho` · ClayFF `ho` · SPC/E `HW`는 ε = 0이다. 산술 혼합으로 섞어도 이 H가 들어간 교차쌍의 ε는 0이 된다.
- 결합 상대가 있어 보통은 안정하다.
- 드물게 전하를 띤 H가 다른 분자의 O에 비정상적으로 가까이 붙는 경우가 있다.
- **검사**: 인장 전 이완 구간에서 분자 간 H…O 최소 거리를 기록한다. 0.8 Å 미만이면 실패로 표시한다(S10 품질 게이트).

### 5.3 전하 합
- 분자별 AM1-BCC 전하 합은 반올림 뒤 정확히 0이 되도록 보정하고, 보정량을 기록한다.
- 광물 슬래브(완전 수산화)의 전하 합은 0이다.
- 조립한 3층 계의 |Σq| < 1e-6이어야 한다. PPPM에서는 알짜 전하가 있으면 배경 전하 보정이 들어가 결과가 왜곡된다.

### 5.4 혼합 규칙 일관성
- `pair_modify mix arithmetic` 뒤에 개별 `pair_coeff i j`로 덮어쓰는 줄이 있으면, 출처를 주석으로 달게 하고 목록으로 보고한다. 조용히 덮어쓰는 줄을 금지한다.
- `dtlab ff cross-table`의 교차항 표와 LAMMPS `write_coeff` 출력이 일치하는지 테스트한다.

### 5.5 단위 · 형식 변환
| 항목 | Amber / 원자료 | LAMMPS | 검사 |
|---|---|---|---|
| LJ | Rmin/2, ε | σ = 2·(Rmin/2)/2^(1/6), ε | V1 에너지 대조 |
| 결합 · 각 | k(r−r₀)² (½ 없음) | harmonic K(r−r₀)² | 같은 값 |
| 이면각 | Σ k(1+cos(nφ−δ)) | fourier: 항 수 m, (K, n, d) 반복 | 항 수 누락 검사 |
| 부정각 | k(1+cos(nφ−δ)) | cvff: K, d(= +1 또는 −1), n | δ가 0 · 180°가 아니면 실패 |
| 1-4 | scee 1.2, scnb 2.0 | special_bonds amber | 다른 값이면 실패 |

### 5.6 병렬 방식과 재현성
- 같은 입력 · 같은 시드라도 **MPI 랭크 수나 OpenMP 스레드 수가 바뀌면** 부동소수 합산 순서가 달라진다. 그래서 궤적이 달라진다.
- 재현성 검사(V8)는 같은 병렬 설정에서만 바이트 수준으로 비교한다. 운영체제 간 비교(V9)는 통계적 허용 범위로 비교한다.

## 7. 한계
- **물 모델 차이:** ClayFF 원 논문은 유연 SPC 물을 썼다. 강체 SPC/E와 짝지은 계면 에너지는 원 논문 조합과 다를 수 있다.
- **AM1-BCC 고정 전하:** 전하가 고정돼 있어 계면의 분극(polarization)을 표현하지 않는다.
- **결정 고정:** 결정을 고정했으므로 광물 쪽 변형은 계산하지 않는다. 파괴는 계면 또는 바인더 내부에서만 생긴다.
- **수치의 출처 표시:** 이 문서와 프롬프트의 수치(전하 · LJ · 실라놀 밀도)는 원 논문과 대조하는 테스트로 확정한다. 확정 전에는 「검증 대상 기대값」으로 표시한다.
