2-1 · DEFINITION

분자동역학(Molecular Dynamics)의 정의

Molecular Dynamics (MD) · 분자동역학
원자 = 질량을 가진 점 · 원자 간 힘 계산 · 뉴턴 운동방정식을 아주 짧은 시간 간격으로 반복 풀이하는 계산 방법
Molecular = 분자 규모의 · Dynamics = 시간에 따라 변하는 움직임(동역학)  →  "분자가 시간에 따라 어떻게 움직이는지를 수치적으로 따라가는 계산"
뉴턴의 제2법칙 (Newton’s second law)
F = ma
가속도 a 는 속도 v 의 시간 변화율 · 속도 v 는 위치 r 의 시간 변화율
v = dr / dt   ·   a = dv / dt = d2r / dt2
m d2r / dt2 = F(r)
원자 i 마다 이 식이 하나씩 · 원자 10만 개면 연립 미분방정식 10만 개
기호 F 힘 · m 질량 · a 가속도 · v 속도 · r 위치(좌표) · t 시간 · d/dt 시간에 대한 변화율(미분)
문제 · 해석적 해의 부재
F 가 모든 원자의 위치에 동시에 의존 → 해석적 해가 존재하지 않음
해법 · 수치 적분 (numerical integration)
짧은 시간 Δt 동안 힘 일정 가정 → 한 스텝 전진 · 힘 재계산 · 반복
"한 스텝 전진" 규칙 = 적분기(integrator) → velocity-Verlet
결과물 · 궤적 (trajectory)
모든 원자의 좌표 · 속도의 시간순 기록 · 물성 = 궤적 평균
양자역학 = 전자까지 계산 · 수백 원자 · 수 ps 한계 · MD = 전자 효과를 힘장(force field)으로 대체 → 수만–수십만 원자 · 수십 ns 계산 — 아스팔트 바인더 한 셀의 규모

velocity-Verlet 적분기의 유도와 구현

유도 · 테일러 전개 (Taylor expansion)
시각 t 의 위치 → Δt 뒤의 위치: 테일러 전개(함수의 다항식 근사)로 계산

v(t+Δt) = v(t) + ½ [a(t) + a(t+Δt)] Δt
𝒪(Δt3) 버린 잔여 오차의 크기 · Δt 절반 → 위치 오차 1/8 (한 스텝 국소 오차 기준)
두 식 모두 시작 · 끝 대칭 → 시간 방향에 대해 대칭 → 시간 가역 · 에너지 드리프트 억제
구현 · 속도의 반스텝 분할 (half-step)
v(t+Δt) 계산에 a(t+Δt) 필수 · a(t+Δt) = 새 좌표 확정 후 계산 가능 → 계산 순서 고정
01v ← v + a(t) Δt / 2앞 반스텝
02r ← r + v Δt좌표 전진
03a(t+Δt) ← F(rnew) / m힘 재계산 · 스텝당 1회
04v ← v + a(t+Δt) Δt / 2뒤 반스텝
01 + 04 합 = 정확히 ½[a(t)+a(t+Δt)]Δt · 반스텝 분할 = 추가 근사가 아닌 계산 순서
힘 계산 스텝당 1회 → 비용의 대부분인 힘 계산 횟수 유지

= 0.00999894 Å/fs

2-4 · EWALD · PPPM

Ewald 분할과 PPPM — 쿨롱을 자르지 않고 분할 후 합산

Ewald 분할 (Ewald summation)
1/r = erfc(αr)/r + erf(αr)/r
점전하마다 반대 부호의 가우스 전하 분포를 더한 차폐 성분(근거리) + 그 분포를 상쇄하는 매끄러운 성분(원거리)으로 분할 · erfc = 여오차함수(complementary error function)
α = 0.25 Å⁻¹ 예시 · 실제 α = LAMMPS가 컷오프 · 허용오차로 자동 결정
세 단계
01
근거리 · 실공간 — erfc(αr)/r 빠른 감쇠 → 컷오프 안의 쌍만 합산 · 12 Å 에서 1/r 의 약 0.002 %
02
원거리 · 역공간(reciprocal space) — erf(αr)/r = 매끄러운 함수 → 소수의 푸리에 성분으로 수렴 · 주기 이미지 전부 포함
03
PPPM(particle–particle particle–mesh) — 전하를 격자에 분배 → FFT 로 02 계산 · 비용 O(N log N), 고전 Ewald 합은 O(N3/2)

APPENDIX · EQUILIBRATION

평형 도달(equilibration)의 판정

01전위에너지 · 부피 · 온도의 이동평균에서 추세 소멸 시점 teq 탐색
02전반부 · 후반부 평균 차이의 표준오차(SE, standard error) 이내 여부 확인
03평형 구간만 물성 계산에 사용 · 앞 구간 전체 폐기
정량 기준 (네 항목 모두 통과)
|⟨A⟩전반 − ⟨A⟩후반| < 2 SE  ·  이동평균 기울기 ≈ 0 (부호 교대)

독립 시드 3개의 평균이 서로 SE 이내 → 평형 인정
물성별 평형화 길이 · #21 "총 시간"의 결정 근거
총 시간 = 스텝 수 × Δt · Δt = 물리적 상한(1~2 fs)으로 고정 → 필요 ns 수 = 스텝 수 = 계산 시간 예산

APPENDIX · AUTOCORRELATION

자기상관(autocorrelation)과 유효 표본 수

C(τ) = ⟨δA(t) δA(t+τ)⟩ / ⟨δA2⟩
τc = ∫0∞ C(τ) dτ
Neff = T / 2τc
상관 시간 τc (correlation time) — 자기상관 C(τ)가 0으로 감쇠하는 데 걸리는 시간
01표준오차 = 총 표본 수가 아닌 Neff 기준 계산
02촘촘한 궤적 저장 → 표본 수만 증가 · 정보량 불변
03점도의 응력 상관 = 긴 τc → 6주차 별도 취급

궤적 길이 T ≥ τc의 수십 배 → 유의미한 평균 · 이 비율 = 계산 시간 예산의 근거
