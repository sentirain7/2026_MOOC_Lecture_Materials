3-1 · TERMS

힘장을 이루는 항

U = Ubond + Uangle + Udihedral + ULJ + UCoulomb
Ubond = Σ kb(r − r0)2
Uangle = Σ kθ(θ − θ0)2
Udihedral = Σ Kn[1 + cos(nφ − γ)]
ULJ = Σ 4εij[(σij/rij)12 − (σij/rij)6]
UCoulomb = Σ qiqj / 4πε0rij
Σ 는 해당 종류의 모든 결합 · 각 · 이면각 · 원자쌍에 대한 합
bonded
결합 길이 · 결합각 · 이면각
분자 하나의 기하 · 유연성 결정 · 알킬 사슬 굽힘 = 이면각 항이 결정
non-bonded
van der Waals(vdW) · 정전기 Coulomb
분자 간 응집 담당 · 밀도 · CED(응집에너지밀도) · 점도 = 사실상 이 두 항에서 산출
이 강좌에서 다루는 범위 — 역설계와의 연결
역설계(inverse design)의 변경 대상 = 힘장 파라미터가 아닌 조성 — 분자 종류 · 개수 · 힘장은 전 과정 고정
따라서 분자 하나의 결합 길이 · 결합각은 설계 변수가 아님 — 분자 내부 기하는 한 번 결정 후 불변
설계 결과의 발현 위치 = 비결합 항 — 분자 간 응집 → 밀도 · CED · 점도 · 부착
조성 변경 → ε · σ · q 의 조합 분포 변화 → 물성 변화로 관측
결합 항 학습 목적 = 설계가 아닌 분자 모양의 응집 영향(사슬 유연성 · 방향족 적층) 이해

3-4 · AUTOCORRELATION

자기상관(autocorrelation)과 유효 표본 수

C(τ) = ⟨δA(t) δA(t+τ)⟩ / ⟨δA2⟩
τc = ∫0∞ C(τ) dτ
Neff = T / 2τc
상관 시간 τc (correlation time) — 자기상관 C(τ)가 0으로 감쇠하는 데 걸리는 시간
01표준오차 = 총 표본 수가 아닌 Neff 기준 계산
02촘촘한 궤적 저장 → 표본 수만 증가 · 정보량 불변
03점도의 응력 상관 = 긴 τc → 6주차 별도 취급

궤적 길이 T ≥ τc의 수십 배 → 유의미한 평균 · 이 비율 = 계산 시간 예산의 근거

APPENDIX · FRACTIONATION

SARA 분획 절차와 역설계의 기준점

SARA(Saturate · Aromatic · Resin · Asphaltene) = 분자식이 아닌 용해도 기준 분류
개별 화합물 식별이 아닌 "용해 용매" 기준 4분획 분리 (ASTM D4124)
S → A → R → As = 극성 · 방향족성 · 분자량이 커지는 순서
같은 분획 안에도 수천 종 혼재 — 대표 분자 = 그 평균 성격의 대리 표현
이 분류로 모델을 구성하는 이유
분획비는 실험으로 측정되는 값 → 모델 조성 적합의 기준점 존재 (다음 슬라이드의 검증 지표)
물성과의 대응 명확 — 노화 = A → R → As 이동 · As 증가 → 강성 · 취성 증가
역설계의 설계 변수 = 네 분획의 비율 + 분획 내 분자 구성
