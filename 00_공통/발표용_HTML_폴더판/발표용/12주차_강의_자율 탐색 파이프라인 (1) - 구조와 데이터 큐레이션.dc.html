12-2 · SUBSTITUTION

골격 고정 · 치환 레버로 후보 생성

01 라이브러리

포화 2 · 방향족 2 · 레진 5 · 아스팔텐 3 — 고리계 · 헤테로원자 유지

02 정수 레버 격자

03 생성 직후 검사
화학 안정성 — 라디칼 0 · 긴장고리(strained ring) 없음 · 생성가능성
SARA(포화분 · 방향족 · 레진 · 아스팔텐) 역할 — 아스팔텐이면 다환방향족 + 헤테로원자 + 알킬곁사슬

적재 조건: 계약 통과 값만 허용

fail-closed 저장
물성 이름은 레지스트리에 등록된 것만 · 단위와 namespace가 정의와 다르면 저장 거부
단일 진실원본 · SSOT(single source of truth)
학습 · 서빙 · 역설계 모두 단일 피처 생성기 사용
스키마 해시
피처 구성 변경 → 해시 변경 — 모델 저장 해시와 불일치 시 서빙 거부
PostgreSQL로 옮기면 (강의용 예시)
CREATE TABLE experiment (
  exp_id        text PRIMARY KEY,
  binder_type   text,
  comp_asphaltene_wt real NOT NULL,
  additive_type text,
  temperature_k real NOT NULL,
  run_tier      text NOT NULL,
  status        text NOT NULL,
  metadata_json jsonb
);
CREATE TABLE metric (
  exp_id text REFERENCES experiment,
  name   text REFERENCES metric_registry,
  value  double precision,
  uncertainty double precision
);

운영 DB = SQLite(SQLAlchemy) — PostgreSQL 이전 시 레지스트리 검사를 외래 키(foreign key) · CHECK 제약으로 DB가 직접 수행

12-4 · OUTLIER

이상치 원인: 값이 아닌 계산 조건

01 증상
체적탄성률(bulk modulus) ~6.8e27 GPa · CED(응집에너지밀도) −3204 MJ/m³
K > 50 GPa 55건 · CED < 0 57건 — 모두 점도(전단) 런
02 원인
전단 런에 NPT(등온등압) 구간 없음 → 고정부피라 var(V) ≈ 0
KT = kBT ⟨V⟩ / var(V) → ∞
폴백(fallback) 경로 + 물리 상한 검사 없음
03 처리
NPT가 없으면 계산하지 않음
0.1 – 50 GPa 범위 게이트
같은 런의 밀도 · MSD(평균제곱변위) · 점도는 유지
재백필 원본 로그에 NPT가 있는 결측 8건은 재계산으로 복원(backfill)
반대 사례 라벨이 빠진 retry 304건은 정상 실험 — 버렸다면 Lignin · SiO2 데이터 대부분을 잃음
원칙 이중 방어 — 계산 진입 조건과 물리 범위 게이트. 기존 저장값: NULL로 정정 또는 학습 시 범위 필터로 제외
