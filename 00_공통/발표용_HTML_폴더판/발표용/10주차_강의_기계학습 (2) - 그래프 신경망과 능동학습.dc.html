10-1 · GRAPH

분자를 그래프로 기재

노드 특징 xv
원소 one-hot · 혼성(hybridization, sp/sp²/sp³) · 형식전하(formal charge) · 고리 포함 여부 · 수소 개수 · 부분전하
엣지 특징 euv
결합 차수 · 방향족 여부 · 고리 내부 여부 · (선택) 결합 길이
왜 그래프인가
원자 번호 순서를 바꿔도 같은 분자로 인식 — 순열 불변성(permutation invariance)이 구조상 자동 보장
10-1 · CRYSTAL GRAPH

결정·벌크 셀: 결합 대신 거리 기준 엣지

엣지 규칙
컷오프 반경 rc 안의 모든 원자쌍 연결 — 셀 경계를 넘으면 주기 영상(periodic image)과 연결 (2주차 주기경계조건)
엣지 특징
결합 차수 대신 거리 dij 사용 — 가우스 기저(Gaussian basis)로 전개한 벡터로 상호작용 세기를 연속적으로 표현
분자 단위 노드
바인더처럼 거대분자 혼합물은 분자 하나를 노드로 설정 — 9주차 수퍼그래프(supergraph) 사례 · 분자쌍 15 Å 컷오프
주의
셀 한 변이 2rc보다 짧으면 한 원자쌍이 여러 영상으로 중복 연결 — 엣지 생성 코드의 처리 여부 확인
10-1 · MESSAGE PASSING

메시지 패싱 한 층의 계산

mv(l) = Σu∈N(v) M(hu(l), euv)   ·   hv(l+1) = U(hv(l), mv(l))
M = 메시지 함수 · U = 갱신 함수 · N(v) = v의 이웃 원자 집합
대표 구조
GCN(graph convolutional network) · GIN(graph isomorphism network) · MPNN(message passing neural network) · GAT(graph attention network) — 메시지 · 갱신 함수의 선택 차이
층이 너무 많으면
모든 노드 표현이 비슷해지는 과평활(over-smoothing) — 잔차 연결(residual connection)로 완화
엣지 활용
방향족 · 결합 차수를 메시지에 포함해야 고리 구조 구분 가능

10-2

등변 GNN과 Graphormer-3D

16분 · 대칭을 보존하는 3D 좌표 사용법

10-2 · SYMMETRY

좌표 사용의 전제 — 회전 · 이동 대칭 조건

불변 · invariance
f(Rx + t) = f(x)
스칼라 출력 — 밀도 · CED(cohesive energy density) · 에너지는 좌표 회전 후에도 같은 값
등변 · equivariance
f(Rx + t) = R f(x)
벡터 출력 — 힘 · 쌍극자는 좌표와 함께 회전 · ML 힘장의 조건
좌표를 그대로 넣으면같은 구조를 회전한 입력마다 다른 답 — 회전 증강(augmentation)으로 근사 가능하나 필요 데이터 대폭 증가
10-2 · EQUIVARIANT GNN

대칭 보존의 두 가지 설계

A · 불변 특징만 사용
mij = φ(hi, hj, dij, θijk)
입력원자 간 거리 dij · 결합각 θijk — 회전해도 변하지 않는 양
대표SchNet (거리) · DimeNet (거리 + 각도) · Graphormer-3D
출력스칼라 물성에 적합 — 힘 = 에너지 미분 F = −∇E
비용낮음 — 층마다 스칼라 특징만 갱신
B · 벡터도 함께 전달
xi′ = xi + C Σj (xi − xj) φx(mij)
입력좌표 · 벡터 특징을 층마다 갱신 — 상대 벡터만 쓰므로 등변
대표EGNN(E(n)-equivariant GNN, 위 식) · PaiNN · NequIP
출력힘 · 쌍극자를 직접 등변으로 — ML 힘장(MLIP, machine-learned interatomic potential)의 주류
비용높음 — 벡터 · 텐서 특징을 층마다 함께 연산
이 강의의 선택밀도 · CED는 스칼라 → A로 충분 · 다음 장의 Graphormer-3D도 거리 · 각도만 쓰는 불변 모델
10-2 · GRAPHORMER-3D

Graphormer-3D: 3D 거리를 어텐션 편향(attention bias)으로 입력

αij = softmaxj ( qi·kj / √d + bij )   ·   bij = Wh eij
eij = 거리 · 각도 등 엣지 특징 · 헤드 h마다 다른 편향
전역 어텐션
모든 노드쌍이 한 층에서 정보 교환 — 메시지 패싱의 L홉(hop) 한계와 과평활 회피
3D 인코딩
원 논문: 거리를 가우스 기저로 전개해 편향 생성 — 거리만 쓰므로 회전 불변
이 과정의 구현
4층 · 4헤드 · 엣지 특징 6개를 선형 사영해 헤드별 편향 · 게이트 어텐션 풀링(attentional aggregation)
