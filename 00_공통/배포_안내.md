## 3. 파일별 사용법

### 3.1 발표용 HTML 덱 (1 · 2번)
**실행 순서**
1. **두 파일을 같은 폴더에 푼다.** 둘 다 `건설소재역설계_MOOC_발표용/` 폴더로 풀리며 하나로 합쳐진다. 하나만 풀면 그림이 빠진다.
2. 로컬 웹 서버로 연다. 파일을 더블클릭(`file://`)하면 슬라이드 런타임이 동작하지 않는다.
   - **Windows:** 폴더 안 `열기_Windows.bat` 더블클릭
   - **macOS · Linux:** 터미널에서 폴더로 이동 → `sh 열기_mac_linux.sh`
   - **직접 실행:** 폴더에서 `python3 -m http.server 8765` → 브라우저에서 `http://localhost:8765/`
3. 첫 화면(`index.html`)에서 주차별 덱을 고른다.
4. 조작: ← → 로 슬라이드를 넘기고, Home · End로 처음 · 끝으로 간다. 「라이브」 슬라이드는 버튼으로 조작한다.

**필요 조건**
- **Python 3:** 로컬 서버를 여는 데 필요하다.
- **인터넷 연결:** 슬라이드 런타임과 글꼴을 온라인에서 받는다. 촬영 현장에 인터넷이 없으면 PDF(3~5번)를 쓴다.

**Windows 주의**
- 압축을 풀 때 경로가 너무 길면(260자 초과) 일부 파일이 빠질 수 있다. `C:\MOOC\` 처럼 짧은 경로에 푼다.
- `열기_Windows.bat`을 처음 실행할 때 방화벽 허용 창이 뜨면 「개인 네트워크」만 허용한다.

### 3.2 PDF (3~8번 · 10 · 11번)
- 압축을 풀어 바로 연다. 동적 도구(버튼 조작 슬라이드)는 PDF에서 첫 화면 상태로만 보인다.

### 3.3 강의 스크립트 (9~11번)
- **구성:** 표지 · 학습목표 · 차시별 시간표 다음에 본문 2단 표가 이어진다.
  - 왼쪽 칸: 슬라이드 화면, 순번, 차시, 배정 시간, 누적 시각
  - 오른쪽 칸: [진행] 지시, 말할 내용
- **표시:**
  - 【콘크리트 예시】 문단은 녹색 배경이다.
  - 부록 슬라이드는 보라색 배경이며, 50분 발표 시간에 포함하지 않는다.
- 주당 50분이다. 강의계획서의 차시별 시간과 ±2분 안에서 맞췄다.

## 4. 확인이 필요한 사항 (요약)
- **`tools/review_todo.md`의 미확인 항목:** 예를 들어 5주차 asphaltene-phenol 화학식, 8주차 O–H 0.75 Å 등이 남아 있다. 촬영용 최종본 전에 확정한다.
