# W09 ↔ MD 워크플로우 ⑤ analyze · ⑥ store · 힘장 검증 · 반복 흔들림

덱 11장(CED 두 경로) · 22장(후처리 체인) · 23장(오차 2종)의 아래 줄 · 출처 줄이 가리키는 보충 문서. 주차 시간(54.5분)이 상한(55분)에 가까워 덱에 새 장을 두지 않고 이 문서에 둔다.
숫자 출처: `../../mdworkflow/README.md`(힘장 검증 · 반복 흔들림 · 2026-11-14 mdai · 4코어 실행) · 실측 = NIST Chemistry WebBook.

## 1. ⑤ analyze (지시문 M-5) = 이번 주 정의와 같은 계산

| 항목 | 이번 주 스크립트(`scripts/`) | MD 워크플로우 ⑤ analyze (`../../mdworkflow/mdwf/analyze.py`) |
|---|---|---|
| 밀도 | `density_from_log.py` · 앞 30 % 폐기 · 블록 10 표준오차 · 전반 · 후반 차 | 생산 구간(P 40 ps · 앞 20 % 버림) thermo Density 평균 · 블록 5개 표준오차(W05) · 전반 · 후반 차 < 1 % 판정 |
| CED | `ced_method_ab.py` · Method A(벌크 마지막 좌표 · 분자 50개 하나씩 run 0) · Method B(기상 분자 1개 NVT 평균 차감) | **Method A 와 같은 정의**: E_inter = E_벌크 − Σ E_분자 하나(같은 좌표) · CED = −⟨E_inter⟩ / ⟨V⟩ |
| 분자 하나의 에너지 | 분자마다 큰 상자에 넣어 run 0 | 생산 프레임마다 분자를 **120 Å 간격 격자로 떼어 놓고 LAMMPS rerun 한 번**(`templates/in.intra` · 전하 직접 합 절단 55 Å · LJ 12 Å) |
| 벌크 에너지 | PPPM · 꼬리 보정 포함 | 같음(PPPM 장거리 전하 · LJ 꼬리 보정) |
| δ | √CED | √CED |
| 결과 파일 | `out/ced.json` · `ced_trace.csv` | `ws/runs/<id>/props.json` · `ced_frames.csv` |

- 데이터셋 전체에서 한 방식 고정(덱 11장): 참고 사례(연구 플랫폼 결과) = B · MD 워크플로우 = A. 두 방식의 값을 한 표에 섞지 않는다.
- 프레임마다 계산하는 이유: 마지막 좌표 한 장의 값은 흔들림이 크다 → 생산 구간 평균 ± 표준오차로 보고(규칙 5 · 덱 22장).

## 2. ⑥ store (지시문 M-6) = 「폴더 하나 → 표 한 줄」

- 계산 1건 = `ws/db/results.csv` 한 줄: id · 조성 · 분자 수 · 원자 수 · T · 프로토콜 · seed · 코어 수 · 밀도 ± · CED ± · δ · 판정 · 힘장 · 벽시계 · 근거(citekey).
- 같은 id 는 거부한다(다시 계산했다면 새 id) · 실패한 계산도 지우지 않고 `ok=False` 로 남긴다 → 실패 기록이 W13 이후 학습 데이터의 편향을 막는다.
- 이번 주 `results.csv`(열 = W16 스키마)와 같은 규칙(입력 = 실험 ID 폴더 · 값은 평균 + 오차 · 출력 = CSV 한 줄).

## 3. 힘장 검증 표 (GAFF2 · AM1-BCC · 표준 프로토콜 130 ps · 4코어)

| 분자(개수) | MD 밀도 g/cm³ | 실측 밀도(NIST 298 K) | MD CED MJ/m³ | 실측 CED = (ΔvapH − RT)/Vm |
|---|---|---|---|---|
| 톨루엔(100) | 0.8703 ± 0.0024 | 0.86238 | 352.3 ± 2.2 | 332.5 |
| n-데칸(47) | 0.734 ± 0.0014 | 0.72664 | 303.0 ± 2.0 | 249.7 |

- 밀도 = 실측보다 1 % 안에서 큼 · CED = 방향족(톨루엔) +6 % · 포화(n-데칸) +21 % → GAFF2 의 응집 과대(특히 알케인)를 알고 결과를 읽는다.
- 표준 프로토콜(④ run): 최소화 → A 섞기 10 ps → B 압축 20 ps → C 이완 20 ps → D 냉각 20 ps → E 평형 20 ps → P 생산 40 ps · 1,500 원자 · 4코어 단독 약 5분. 짧은 교육용 프로토콜 → 값은 비교용.
- 덱 12장의 톨루엔 50분자 CED 374.9 MJ/m³ 는 이번 주 짧은 실행(수렴 전 · Method A/B 체인)의 값이라 이 표와 직접 비교하지 않는다(실행 길이 · 분자 수 · 계산 경로가 다름).
- 실측 출처: NIST Chemistry WebBook(톨루엔 C108883 · n-데칸 C124185 · 밀도 = Lemmon & Span 2006 상태식 · ΔvapH = Majer–Svoboda 식 298.15 K).
