## §3 메시지 패싱 식 (10주차 #8)
m_v⁽ˡ⁾ = Σ_{u∈N(v)} M(h_u⁽ˡ⁾, e_uv) · h_v⁽ˡ⁺¹⁾ = U(h_v⁽ˡ⁾, m_v⁽ˡ⁾)
- M = 메시지 함수 · U = 갱신 함수 · N(v) = 이웃 원자 집합 · L층 = L결합 떨어진 원자까지 · 보통 L = 3 ~ 5
- 대표 구조: GCN · GIN · MPNN · GAT · 메시지 · 갱신 함수의 선택 차이
- 과평활(over-smoothing): 층이 많으면 모든 노드 표현이 비슷해짐 → 잔차 연결로 완화
- 엣지 활용: 방향족 · 결합 차수를 메시지에 넣어야 고리 구조 구분(벤젠 ↔ 사이클로헥세인)
- 이 저장소 `mpnn_forward.py`: M = W_m h_u(엣지 특징 생략) · U = tanh(W_s h_v + m_v) · 판독 = Σ_v w_r·h_v

## §4 불변 · 등변 (10주차 #11 · #12)
- 불변: f(Rx + t) = f(x) · 밀도 · CED · 에너지
- 등변: f(Rx + t) = R f(x) · 힘 · 쌍극자 · ML 힘장의 조건
- 좌표를 그대로 넣으면 같은 구조를 돌린 입력마다 다른 답 → 회전 증강(augmentation)으로 근사 가능하나 필요 데이터 대폭 증가
- 설계 A(불변 특징만): m_ij = φ(h_i, h_j, d_ij, θ_ijk) · SchNet(거리) · DimeNet(거리 + 각도) · Graphormer-3D · 힘 = −∇E · 비용 낮음
- 설계 B(벡터 전달): x_i′ = x_i + C Σ_j (x_i − x_j) φ_x(m_ij) · EGNN · PaiNN · NequIP · MLIP 주류 · 비용 높음

## §5 Graphormer-3D (10주차 #13 · #14)
α_ij = softmax_j(q_i · k_j / √d + b_ij) · b_ij = W_h e_ij
- e_ij = 거리 · 각도 등 엣지 특징 · 헤드 h 마다 다른 편향 · 전역 어텐션으로 L홉 한계와 과평활 회피
- 원 논문: 거리를 가우스 기저로 전개해 편향 생성(회전 불변)
- COMID 구현: 4층 · 4헤드 · 엣지 특징 6개(거리 · 각도 · 수소결합 · π–π · LogP 차 · Tanimoto)를 선형 사영해 헤드별 편향 · 게이트 어텐션 풀링
- 입력 경로: 셀 .mol → GetMolFrags → 노드 = 분자(원자 좌표 평균 · RDKit 기술자 10: 분자량 · TPSA · LogP …) → 엣지 15 Å → 시스템 조건(분자 수 · 온도)은 MLP 로 변환해 모든 노드에 합산

## §6 트리 모델용 32 특징 (10주차 #15)
sum X = Σ_s n_s X_s · mean X = sum X / N_frag · std X = √(Σ_s n_s (X_s − mean X)² / N_frag) · 기술자 10 × {mean, sum, std} + {N_frag, T} = 32
- 두 경로를 함께 두는 이유: 트리 = 기준선 · 새 모델은 challenger 로 학습 → holdout 이 champion 보다 높을 때만 승격

### 16.1 GP 사후식 (이전 17장 EQ · 18장 「GP = 손전등」 으로 통합)
- 식 원문: μ(x*) = k*^T(K + σ_n^2I)^−1y  ·  σ^2(x*) = k(x*, x*) − k*^T(K + σ_n^2I)^−1k*
- 기호표: K = 학습점끼리의 커널 행렬 · k* = 새 점 x* 와 학습점의 커널 벡터 · k(x, x′) = σ_f² exp(−‖x − x′‖² / 2ℓ²) + σ_n²δ · ℓ · σ_n = 길이척도 · 관측 잡음.
- 그림 설정: 관측 6점(가정 함수 · 잡음 σ 0.05) · 고정 커널 σ_f 0.6 · ℓ 0.15 · 연구 플랫폼 설정 RBF + WhiteKernel.
