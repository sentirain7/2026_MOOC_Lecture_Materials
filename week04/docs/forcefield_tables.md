# week04 보충 표 · 덱 v3 에서 뺀 표 · 세부 (내용 보존)

W04 덱 v1(28장 · `decks/v1/W04_힘장.html`)의 표 7장 가운데 v3 덱(26장)에 그림 · 카드로 압축되지 않은 세부를 여기에 둔다. 덱의 해당 장 번호 = v3.

## 1. 항별 상수 결정 방법 (덱 4 · 5장)
| 항 | 상수 | 결정 방법 | 신뢰도 |
|---|---|---|---|
| 결합 신축 | k_b · r₀ | QM 최적화 길이 + 진동수 · X선 결정 구조 · IR/Raman | 높음 |
| 결합각 | k_θ · θ₀ | QM 각도 스캔 + 결정 구조 통계 | 높음 |
| 이면각 | V_n · n · γ | QM 회전 곡선의 잔차에 적합 · 분해 비유일 | 중간 |
| 반데르발스 | ε · σ | 액체 밀도 · 증발열 실험값에 적합 | 물질군 안에서 높음 |
| 정전기 | q_i | QM ESP 에 RESP · AM1-BCC 적합 · 형태 의존 · 분극 없음 | 중간 |

아래 세 줄은 나머지 항과 함께 맞춘 값 → 한 항만 교체하면 균형 붕괴(W08).

## 5. ReaxFF 대 고전 힘장 (덱 8장 카드의 세부)
- 고전(GAFF2): 결합 토폴로지 = 입력 · 전 과정 고정 · 전하 AM1-BCC 분자별 1회 · Δt 1.0 fs · 조합 규칙으로 이종쌍 · 산화 · 수화 반응 표현 불가.
- ReaxFF: BO_ij = f(r_ij) 매 스텝 판정 → 생성 · 절단 허용 · 전하 QEq 매 스텝 · Δt 0.5 fs · 고정 ε σ q 부재 → 고전 힘장과 혼용 불가. 예: 산화 시 설폭사이드가 케톤보다 먼저 생성(Cui & Wang 2023).
- 플랫폼 위치 = 검증 경로: 밀도 · CED 이상치(|z| > 2) 계만 약 10만 원자로 재계산 → CONSISTENT · DIVERGENT (연구 플랫폼 docs/DECISION_RULES.md R1 · R4 · R6). 수식은 W12.

## 6. 부분전하 방법 7종 (덱 14장 산점의 원본)
| 방법 | 근거 | 비용 | 쓰는 곳 |
|---|---|---|---|
| AM1-BCC | 반경험적 AM1 + 결합별 보정 | 초 | 이 강좌 기본값 · 유기 분자 전부 |

## 7. 전하 결정 시점 3 (덱 14장 카드의 세부)
- 고정전하: 힘장 파일에 타입 · 사이트별 사전 지정 · 비용 0 · ClayFF Si +2.1 · O −1.05 · 수산기 O −0.95 / H +0.425 · SPC/E 물 O −0.8476 / H +0.4238 · 한계: 목록 밖 골격 불가.
- AM1-BCC(이 강좌): 분자 생성 시 1회 → 라이브러리 저장 · 재사용 · antechamber 600 s → 실패 시 sqm_robust 3600 s 1회 → 재실패 시 수동 검토 · SCF 미수렴 분자(CNT 등)는 학습 데이터 제외 · 한계: 분극 없음 · 형태 의존.
- QEq: 매 스텝 E(q) = Σ(χ_i q_i + ½J_i q_i²) + Σ q_i q_j J_ij 최소화 · Σq = 0 · 환경 변화 → 전하 이동 · ReaxFF 검증 경로 전용 · Δt 0.5 fs · 발산 시 Δt 축소.
- 선택: 결합 불변 → 고정전하 · AM1-BCC · 전하 이동 자체가 관심 → QEq · 한 셀 안 전하 척도 통일(W08). 출처 연구 플랫폼 ff-standard-reference · DECISION_RULES R1 · R2 · R6.

## 8. 이종 분자 사이 = 비결합 2항 (덱 25장)
- 반데르발스: ε σ = 타입별 값 → 이종쌍 구성에 조합 규칙 필수 · 함수 형태(12-6 / 9-6) · 규칙이 다르면 구성 불가 · ca–hc 산술 σ 2.958 · 기하 2.936 · 6제곱 3.058 Å.

- 간접 경로: 결합 항 · 1-4 축소는 분자 형태 · 전하 분포를 거쳐 비결합 에너지에 반영 · special_bonds 는 계 전체 하나 → 내부 항도 동시 확인.

## 10. 컷오프 · Ewald · PPPM (덱 18장)
- r = 3 Å 에서 1 로 정규화하면 12 Å 에서 r⁻⁶ 은 0.0002 · r⁻¹ 은 0.25. 껍질 기여 ∝ U × 4πr² → r⁻⁶ 은 r⁻⁴ 로 수렴 · r⁻¹ 은 r 로 발산(합 비수렴).
- 절단 증상: 힘 불연속 → 에너지 드리프트 · 이온 · 극성기 r_c 부근 인위 배열 · 정전 에너지 과소 → 밀도 · 압력 · Tg 편향.
- Ewald: 1/r = erfc(αr)/r(근거리 · 실공간 컷오프 안) + erf(αr)/r(원거리 · 역공간 소수 푸리에 성분 · 주기 이미지 전부 포함). erfc(α r_c) = erfc(3) ≈ 2.2 × 10⁻⁵(α 0.25 Å⁻¹ · r_c 12 Å). α 는 LAMMPS 가 컷오프 · 허용오차로 자동 결정.
- PPPM = particle–particle particle–mesh · 전하를 격자에 분배 → FFT · O(N log N)(고전 Ewald O(N^1.5)) · 진공 단분자 계는 kspace 없이 coul/cut. 주기 이미지까지 1/r 을 그냥 더하면 조건부 수렴.
- 연구 플랫폼 기본 설정(ff_stack.py): `pair_style lj/cut/coul/long 12.0` · `pair_modify mix arithmetic` · `kspace_style pppm 1.0e-4` · `kspace_modify slab 3.0`(층상 셀만).

## 11. 이웃 목록 인수 (덱 19장)
```
neighbor      2.0 bin
neigh_modify  every 1 delay 0 check yes
```
| 인수 | 뜻 |
|---|---|
| 2.0 | skin 두께(Å) · 컷오프 바깥 추가 목록 범위 |
| bin | 격자 탐색(cell list) · 대안 nsq = 전수 검사 |
| every 1 · delay 0 | 매 스텝 재구성 여부 점검 · 재구성 후 대기 없음 |
| check yes | 원자 이동 ≥ skin/2 일 때만 재구성 |

모든 쌍 매 스텝 = O(N²) · N 10만 → 쌍 50억 · 불가. 이웃 수 ≈ ρ(4/3)π(r_c+skin)³ = N 과 무관 → O(N). skin 과소 → 재구성 빈번 · dangerous builds(이웃 누락) · 과대 → 목록 증가로 힘 계산 지연. 로그의 "dangerous builds" 경고 = skin 부족(W07 실패 감지).

## 12. 분자 준비 4단계 · 라이브러리 (덱 10장)
SMILES → 3D 좌표(수소 부착 · 에너지 최소화) → GAFF2 타입 → AM1-BCC 전하 → LAMMPS data 파일(타입 · 결합 목록 · 전하 · 좌표). 분자당 1회 · 라이브러리 저장. Li & Greenfield 2014 가 SHRP 코어 아스팔트 12종 분자를 이 절차로 구축 · 본 프로젝트 = 12종 + 고황 1종 = 13종 · 역설계는 개수 비율만 조정.

## 14. 덱에서 옮긴 식 (2026-11-14 · 규칙 16 · 이론 · 수식 비중 축소)

덱에는 핵심 식 한 줄(4장 「U = 결합 + 각 + 이면각 + 반데르발스 + 정전기」)과 말 식만 남겼다. 아래는 덱 화면 · 그림 · 노트에서 뺀 기호 표기와 표 원문이다(삭제 금지 · 숫자 그대로).

### 14.1 힘장 5항의 기호 (덱 4장 카드 · 애니 라벨)
- ① 결합 신축 · k_b r₀ · ½k_b(r − r₀)²
- ② 결합각 · k_θ θ₀ · ½k_θ(θ − θ₀)²
- ③ 이면각 · V_n n γ
- ④ 반데르발스(LJ) · ε σ · 4ε[(σ/r)¹² − (σ/r)⁶]
- ⑤ 정전기(쿨롱) · q · q_i q_j / 4πε₀ r

### 14.2 함수 계열 비교 표 (덱 6장 표 원문 · 덱에는 카드 3장으로 요약)
| 항목 | GAFF2 | OPLS-AA | COMPASS | ClayFF |
|---|---|---|---|---|
| 계열 | Class I | Class I | Class II · 교차항 | 무기 · 점전하 |
| 반데르발스 | LJ 12-6 | LJ 12-6 | LJ 9-6 | LJ 12-6 |
| σ 조합 규칙 | 산술 (LB) | 기하 | 6제곱 (WH) | 산술 |
| 1-4 축소 vdW / 쿨롱 | 0.5 / 0.8333 | 0.5 / 0.5 | 축소 없음 | 결합 없음 |
| 부분전하 | AM1-BCC · 분자별 | 타입별 고정 | 결합 증분 | 고정 (Si +2.1) |
| 적합 대상 | 응축상 실험 물성 | 순수 액체 물성 | QM + 응축상 | 광물 구조 · 물 |

- 그림 라벨 원문: 「12-6: 4ε[(σ/r)¹² − (σ/r)⁶]」 · 「9-6: ε[2(σ/r)⁹ − 3(σ/r)⁶]」 · 「같은 우물(ε · r_min) · 인력은 둘 다 r⁻⁶」 · 가로축 r / σ · 세로축 U / ε.
- 부제 원문: 「인력 항은 둘 다 r⁻⁶ · 차이 = 반발 벽의 기울기 · 같은 ε · σ 입력 → 다른 곡선 → 값 상호 교환 불가」.

### 14.3 조합 규칙 식 (덱 7 · 11 · 12장)
- 이종쌍 세기: 산술 · 기하 ε_ij = √(ε_i ε_j) · 6제곱(WH) ε_ij = 2√(ε_i ε_j) · σ_i³σ_j³ / (σ_i⁶ + σ_j⁶) → 어느 규칙이든 한쪽 ε ≈ 0 이면 인력 소실 · 표면 O(ε 0.155) ↔ 유기 C/H 분산력.
- 이종쌍 크기: 산술(LB) σ_ij = (σ_i + σ_j)/2 · 기하 σ_ij = √(σ_i σ_j) · 6제곱(WH) σ_ij = [(σ_i⁶ + σ_j⁶)/2]^(1/6) · 순서 기하 ≤ 산술 ≤ 6제곱(멱평균 부등식).
- 접촉 거리: r_min = 2^(1/6) σ_ij · 우물 바닥 거리 3.3 ~ 3.8 Å.
- 정의 카드 원문(11장): 조합 규칙 = 「같은 타입끼리의 ε_ii σ_ii 로 이종쌍 ε_ij σ_ij 를 만드는 식」 · 부분전하 = 「원자마다 배정한 소수 전하 q_i(e)」 · 이웃 목록 = 「r_c + skin 안의 원자 목록 · 몇 스텝 재사용 → 쌍 탐색 O(N²) → O(N)」.

### 14.4 이전 13장 「ca–hc 규칙 산술 → 6제곱」 바꿔 보기 (덱 12장으로 통합)
| 규칙 | 힘장 | σ_ij (Å) | ε_ij (kcal/mol) | r_min (Å) |
|---|---|---|---|---|
| 산술 LB (pair_modify mix arithmetic) | GAFF2 · CHARMM · ClayFF | 2.958 | 0.0453 | 3.320 |
| 기하 | OPLS | 2.936 | 0.0453 (산술과 같은 식) | · |
| 6제곱 WH | COMPASS | 3.058 | 0.0355 | 3.433 |

- 곡선 입력값(덱 그림): 산술 2.9577 · 0.045333 · 6제곱 3.0583 · 0.035485. 접촉 거리 이동 0.11 Å.
